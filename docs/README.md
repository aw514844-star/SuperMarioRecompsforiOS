Super Mario Recompilations for iOS

A collection of high-performance native ports of classic Super Mario and Nintendo titles, optimized specifically for iOS devices.
This repository provides everything you need to experience these iconic titles natively on your iPhone or iPad, utilizing modern recompilation techniques for flawless performance and features.

🎮 Included Games

• Super Mario 64 – The revolutionary 3D platformer, fully optimized. (Not Released Yet)
• Super Mario Sunshine – High-definition tropical adventures with FLUDD.
• Super Mario Galaxy – Gravity-defying interstellar gameplay.
• Paper Mario – The classic RPG adventure with crisp text and rendering.
• Super Smash Bros. Melee – High-speed multiplayer brawling on the go.

✨ Features

• Native Performance: Built directly for iOS hardware, bypassing traditional heavy emulation overhead.
• Controller Support: Full compatibility with MFi controllers, Xbox, PlayStation, and MFI controllers.
• Touch Controls: Fully mapped on-screen overlays for playing without a controller.

🚀 Installation & Setup

Please head over to the Releases section of this repository to download the pre-compiled binaries and view detailed setup instructions for each game.

Prerequisites

• An iOS device running iOS 15.0 or higher.
• A method to sideload .ipa files.
• Your own legally obtained game ROMs/ISOs for asset extraction where required. (But there are links for people who want to pirate in the releases)

How to build

People who want to make some of these games by themselves just has to fork this repository, go on actions, press build for iPhones, press run workflow and select the game. Making it usually takes 15-25 minutes. After it finished press summary, scroll down, download the zip, uncompress the zip, open the folder and then sideload the ipa in there.
